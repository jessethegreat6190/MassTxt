# GitHub Repository Description

## About (GitHub repo About section — max 350 characters)

```text
Offline Windows bulk SMS desktop app. Send via USB GSM modem or Android phone, manage contacts/groups/templates, schedule messages, send Long SMS and Flash on screen (Class 0), buy bundles with the USSD Dial Pad, and audit Sent/Failed/Delivered records. No gateway fees.
```

## Release Description (use when publishing a release)

```text
## MassTxt v2.2.0

Bulk SMS from Windows via USB GSM modem or Android phone — no API costs, no internet required.

### What's New in v2.2.0
- USSD Dial Pad for buying/checking SMS bundles
- GSM modem uses AT+CUSD and shows the network reply
- Android phone opens the dialer with the code prefilled
- Editable MTN/Airtel bundle shortcuts in Settings
- Confirmation required for every dial
- Compose options: Long SMS and Flash on screen (Class 0 FLASH SMS)
- Enter adds a new line in the SMS body
- All-time Sent / Failed / Delivered accountability section
- Bulk sends honour the selected Android phone or GSM modem
- Flash SMS data coding configurable (240 / 16)
- GSM modem sending via AT commands
- Contacts, groups, templates, Excel/CSV import
- Scheduled messages, delivery reports, and inbox reading
- Installer and portable EXE builds

### Downloads
| File | Description |
|------|-------------|
| MassTxt.Setup.2.2.0.exe | Windows installer (recommended) |
| MassTxt-Portable.exe | Portable — no installation needed |

### Requirements
- Windows 10/11 (64-bit)
- USB GSM modem, or Android phone with USB Debugging enabled
- Data USB cable
```
